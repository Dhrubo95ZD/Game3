# Asset provenance

All shipped bitmap artwork in version 0.1 was generated specifically for Neon Rift
with OpenAI's built-in image generation workflow on 2026-09-08. No stock packs,
traced art, or existing game characters were used.

## Visual direction

Original hand-painted Japanese animated feature-film aesthetic with painterly
natural environments, grounded manufactured technology, teal/gold clean-tech
accents, full-coverage practical armor, and readable mobile-game silhouettes.

## Shipped assets

| File | Purpose |
| --- | --- |
| `class_lineup.webp` | Canonical Slayer, Gunslayer, and Mecha selection key art |
| `arena_background.webp` | Ridgeline combat courtyard |
| `slayer_sheet.webp` | Eight-frame Slayer movement and attack sheet |
| `sentinel_sheet.webp` | Six-frame autonomous training sentinel sheet |
| `combat_fx_sheet.webp` | Six physical/electrical combat effects |
| `game_icon.webp` | Android launcher artwork |

Sprite and effect sheets were generated against a pure-green production backdrop,
then mechanically chroma-keyed to real alpha transparency. Character identity,
palette, modest armor, grounded technology, and prohibited-content constraints
were specified consistently in every generation prompt.
